## ✨ Features

🎯 **Two-Player Gameplay** - Play against a friend with X and O symbols  
✅ **Input Validation** - Ensures all moves are valid  
🏆 **Win/Draw Detection** - Automatically detects winners or a draw  
🎨 **Clean Interface** - Clear and intuitive command-line display  
⚡ **Quick Play** - Fast and responsive gameplay

## 🛠️ Prerequisites

Before you begin, ensure you have:

- 🐍 Python 3.x installed
- Terminal or Command Prompt access
- A friend to play with! (or play both sides yourself 😉)

## 🚀 Getting Started

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd tic-tac-toe
   ```

2. **Run the game**
   ```bash
   python tictactoe.py
   ```
   
   > 💡 **Tip**: Make sure you're in the correct directory where `tictactoe.py` is located!

## 📜 Game Rules

1. 🎯 **Objective**: Be the first to get 3 of your marks in a row (horizontally, vertically, or diagonally)
2. 👥 **Players**: X goes first, followed by O
3. 🎮 **Turns**: Players alternate turns, placing their mark in an empty cell
4. 🏆 **Winning**: First to 3 in a row wins!
5. 🤝 **Draw**: If all 9 cells are filled with no winner, it's a draw

```
 1 | 2 | 3 
-----------
 4 | 5 | 6 
-----------
 7 | 8 | 9 
```
*Use the numbers 1-9 to place your mark on the corresponding cell*
